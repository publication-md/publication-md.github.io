# publication-md

A plain-text format for transcribed publications, and the tools to make them. A periodical issue,
a book or a report is stored as Markdown files, one for each page of its document (like a PDF), with
YAML metadata.

## Projects

- [publication-md](https://github.com/speleo-se/publication-md): the format and its tools.
- [PageSequence](/pagesequence/): maps the pages of a document to the labels printed on them.
  The source is on [GitHub](https://github.com/publication-md/pagesequence).
